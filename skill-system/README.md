# Skill system

This repository is the canonical home for Filipe's portable personal coworkers, standalone capabilities, and their maintenance process. Project-specific workflows remain in the repositories they operate.

```text
coworker plugin
└── several skills serving one mission

standalone capability
└── one independent skill
```

## Update loop

1. Use the skill on real work.
2. Record specific friction, missing context, or repeated useful behavior.
3. Propose the smallest change to the canonical source.
4. Get the relevant owner's approval for shared or sensitive skills.
5. Edit and validate the canonical source.
6. Merge, reinstall or update, and test discovery in a new Codex task.
7. Update the catalog when ownership, status, location, or replacement changes.

Skills may suggest improvements but never rewrite themselves without approval.

See `catalog.json` for the machine-readable inventory.
